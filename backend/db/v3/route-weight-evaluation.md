# 시설 가중치 정책 평가 계획

기본 정책은 A다. CCTV 0.02·가로등 0.04·경찰시설 0.04 및 검색 반경은 실측으로 보정되지 않았다. 회귀 테스트 통과와 실제 보행 안전성 검증을 구분한다.

| 정책 | 시설 설정 | 계산 | 연령 보정 |
|---|---|---|---|
| A: 공통 기준 | CCTV 0.02, 가로등 0.04, 경찰시설 0.04, 나머지 0 | 고정 기준·합계 상한 0.10 | 0 |
| B: 이전 실험 | 09의 연령별 값 | 이전 0.85 기반·Min-Max | 기존 시설 배수 |
| C: 검증 후 후보 | A 공통값 | A 기준 | 검증된 보행 위험 요소만 별도 비용에 추가 |

C는 현재 배포하지 않는다. 검증된 보행 위험 입력이 없는 지금은 보정이 0이므로 A와 같다. 가중치 변경과 정규화 제거 효과를 분리하기 위해 '이전 가중치+고정 기준' 실험도 기록한다. B는 새 API의 예산 제한에 맞추려고 임의로 축소하지 않고 실험 구현을 분리한다.

## 동일한 출발·도착 25쌍

도로망 스냅샷·시설 원본·시간대·생년월일을 고정한다. 다음 유형별 5쌍을 **현장 확인 후** 선정하고 두 연령대를 각각 실행한다.

1. 경찰시설 가까운 골목과 조명 있는 상가 도로가 경쟁하는 경우.
2. 보도·횡단 시설이 있는 길과 차량 통행 도로가 경쟁하는 경우.
3. CCTV 밀집 구간과 다른 예방 환경을 가진 구간이 경쟁하는 경우.
4. 주간/야간 또는 영업/미영업 조건이 달라지는 경우.
5. 정보 누락이 있거나 대안의 거리가 크게 다른 경우.

확인 전에는 임의로 '안전한 정답'을 붙이지 않는다. 임의 노드 쌍을 실행한 것으로 현장 검증 25쌍을 완료했다고 보고하지 않는다.

## 기록할 지표

- 길이 및 우회율: `(정책 길이 / 최단 길이 - 1) × 100`.
- 두 정책 경로의 겹치는 간선 길이 / 합집합 간선 길이. 변화 자체를 개선으로 간주하지 않는다.
- 확인된 위험구간을 지난 거리·횡단 횟수·보도 단절·제한속도와 판정 근거.
- 위험 비용·시설 보너스·연령 보정을 분리한 내역.
- 실제 조도·시야·카메라 방향·비상벨 작동·점포 영업 여부·시간대.
- 누락률, 현장 조사자·전문가 판정, 불확실성.

위험 회피율은 실제 범죄·사고 자료나 확인된 판정이 있어야 평가한다. 목업 위험구역 회피는 '목업 위험 노출'로만 기록한다.

## 현재 데이터와 C 후보

저장소 `road_network.json` 도로 1,061개 중 `sidewalk` 태그는 62개, `maxspeed`는 176개, `lit`는 2개에 있었고 횡단 노드는 49개였다. 이는 스냅샷의 태그 보유 수이며 정확성을 검증한 결과가 아니다. 태그 누락을 보도 부재나 안전함으로 해석하지 않는다. 현재 계산기는 이 교통 태그를 사용하지 않는다.

보도·속도·교통량·횡단 난이도·사고 이력은 후보로 남긴다. 데이터 최신성·커버리지·간선 연결 방법과 연령 보정 근거를 확인한 뒤 비용을 설계한다. 이때도 범죄 예방 관련 공통 위험을 유지해 교통 요소만으로 경로를 정하지 않는다.

## 조정 기준

평가 전에 허용 우회율과 위험 노출 악화 금지 기준을 팀에서 정한다. 현장·전문가 판정과 비교해 순위 오류를 줄이는 값과 검색 반경을 찾는다. 25쌍은 개발·검토용이며 다른 출발·도착점에서도 확인한다. 튜닝에 사용한 경로만으로 계수를 확정하지 않는다. 검증 전에는 연령별 배수를 활성화하지 않는다.
